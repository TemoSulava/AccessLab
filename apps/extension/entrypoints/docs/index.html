AccessLab

Find accessibility barriers. Inspect the cause. Verify the fix.

Scope

Explicitly activated on ordinary HTTP and HTTPS pages. Top document only; iframes are excluded. Closed shadow roots cannot be inspected. Audits exceeding 5,000 elements or 1,000 interactive targets (including open shadow roots) fail explicitly before running to preserve page responsiveness. A zero-finding result does not establish accessibility compliance. Manual checks remain.

Privacy

No accounts, server, telemetry or remote scans. Reports and active effects stay in document memory. Only validated preferences are stored. Export happens only on your request; locators can reveal page structure.

Reset and close

Reset clears active modules and reports. Close removes AccessLab resources and restores prior focus if the element still exists. Reload restores a clean inactive document. During development hot reload or extension removal, hard-reload the page if resources remain.

Previews and export

Previews require a static selected region of at most 500 elements. They cannot safely cover html/body, positioned descendants or unavailable custom-element internals. Baseline scans suspend preview effects. Export JSON or Markdown after reviewing it locally; URL query/fragment, page title, snippets and input values are omitted. Each output is limited to 5 MiB with explicit error rather than silent truncation. Native host modals may cover the panel; close the host modal to return.

Manual checks

Test keyboard navigation, screen-reader output, content clarity and usability with disabled people. Visual rendering previews are approximations, not disability simulations.
