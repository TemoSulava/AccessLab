# Architecture

A pnpm workspace separates the WXT/React extension, deterministic Vite demo, strict contracts, lifecycle/overlay core and locally bundled modules. No backend exists.

The production background action checks the parsed page URL, injects into frame 0 using activeTab/scripting, then sends a bounded schema-v1 activation command and requires a matching acknowledgement within five seconds. Runtime-only entrypoints avoid broad static host permissions. Restricted pages get actionable badge/title feedback. The test build adds only localhost host access and a worker-only activation hook; native production action tests exercise the actual permission grant independently.

An isolated-world document singleton owns PageController and React's Shadow DOM panel. Repeated activation reveals it. Controller owns module manager, overlay layer, effect registry, mutation/navigation tracking, scan generation and session element references. No page-window command channel exists. Close disposes and removes resources, restores connected prior focus and clears the singleton; reload returns to inactive baseline. Reset aborts modules, invalidates publication and clears reports.

ModuleManager validates configurations, enforces API version/unique IDs, serializes replacement intent, handles exclusive preview groups, aborts before cleanup and aggregates disposal failures. Every listener/timer/observer/node/style/attribute cleanup belongs to an effect registry. Late registration disposes immediately. Only the current non-aborted module instance can publish events. The packages/modules/src/registry.ts static registry is the only module loading mechanism; contributor controls are explicit local defaults and appear generically in Inspect.

axe-core runs against the top document with owned roots/resources and frames excluded. A bounded preflight counts open-shadow elements before engine startup. Reports normalize engine fields into strict contracts and validate version/5 MiB budget before publication, maintain separate violations/needsReview and capture session element references. The panel paginates findings; failed locators never re-query a changed page into a wrong target. Document/known open-shadow mutations and SPA URL changes stale reports; generation/AbortSignal prevent late publication after Reset.

Target inspection uses batched live geometry, bounded overlays and explicit heuristics; focus trail listens to real composed focus events, excludes owned controls and retains bounded connected history without typing values. Preview effects apply only to safe selected static regions using owned styles/attributes and optional local SVG matrices. Baseline audits suspend effects through registered suspend/resume hooks; Reset removes hooks so a pending scan cannot resurrect them. Host inline styles are never overwritten.

Export builds schema-v1 text from validated whitelisted data, redacts URL query/fragment/user info again, optionally includes separate observations, escapes Markdown and rejects outputs above 5 MiB. User-triggered Blob downloads are the only export mechanism; URLs are revoked. Production builds generate actual bundled-package license inventories and reproducible ZIP/checksum artifacts.
