# T05 — page controller, ownership and overlays
Singleton document controller mounts a Shadow DOM host and separate Shadow DOM overlay layer. Overlays use measured viewport rectangles and requestAnimationFrame batches on scroll/resize, cap 200 outlines and remove disconnected targets. Owned nodes are ignored by the bounded active MutationObserver; document mutations increase revision and invalidate existing reports. URL changes are checked by popstate/hashchange and a 1-second timer without patching history. Close disposes observers/timers/listeners/overlays and restores prior connected focus. Reopening starts a new controller; document reload is inactive.
