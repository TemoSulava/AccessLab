# Real extension automation
Playwright persistent Chromium context loads actual WXT-built files; worker discovery fails if the extension is absent. Chromium channel with full browser headless (not headless shell) is required. Test builds define a worker-only activation hook, restrict it to http://127.0.0.1:4173/ and add that single host permission. Production does not contain that hook or extra permission. Tests execute real scripting injection, not a web-app substitute. Automated tooling cannot press browser chrome toolbar in this environment. Current stable Chrome toolbar/action authorization remains a human release gate. Never add production all-sites permissions to facilitate tests.
