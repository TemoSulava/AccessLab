# Selected-region preview strategy
T11 Chromium spike applied a body filter on the deterministic fixture: fixed-marker geometry changed; removing it restored baseline. Region-only filtering preserved fixed marker, sticky header and canvas geometry. Whole-page root filtering therefore is not shipped.

Use an explicitly selected CSS-selector region (keyboard accessible) with ≤500 elements; reject html/body, fixed/sticky/absolute descendants, inline-important host filters and custom elements with unavailable internals. No reparenting or host inline-style changes. Unique owned attribute/stylesheet implements the filter; baseline computed filter is composed with the approximation, refreshed on bounded active mutations. Preview teardown removes only owned resources and preserves host edits. Guard failures are explicit; native top-layer modal workflows may obscure injected UI and require closing the modal before panel interaction.

Each preview registers baseline suspend/resume callbacks. Audits disable the owned stylesheet through CSSOM and restore only still-registered effects. Reset/replacement unregisters the old effect, so a late audit cannot restore it. Owned stylesheet/attribute mutations are ignored by report invalidation; real host changes still invalidate. Grayscale/blur are rendering approximations, not disability simulation. No default active effect or global filter.
