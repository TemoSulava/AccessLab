Machado, Oliveira & Fernandes (2009), A Physiologically-based Model for Simulation of Color Vision Deficiency, DOI 10.1109/TVCG.2009.113. SVG feColorMatrix is locally created with color-interpolation-filters=linearRGB. Reference implementation converts sRGB bytes to linear RGB, multiplies the 3x3 matrix, clips gamut to [0,1], then converts to sRGB. Numeric tests include independent known red expectations, black/white and bounds; real Chromium screenshots sample each primary swatch with a 3-byte-channel tolerance using a CRC-checked standard-library PNG reader. Baseline host filters are tested separately; numeric fixture removes host sepia to isolate the matrix.

Scope is the same safe explicit region as grayscale/blur; resources belong to the effect registry and exclusive group. This is a rendering approximation, not medical realism or an account of any person's perception. No default active preview. Human screenshot and participant evaluation remain separate gates.
