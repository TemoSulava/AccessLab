# Verification and production packaging

Use Node 24.19.0, pnpm 11.19.0 and Python 3. Run `pnpm install --frozen-lockfile`, `pnpm exec playwright install chromium`, `pnpm verify`, then `pnpm package`. On a fresh Linux runner, `pnpm exec playwright install --with-deps chromium` installs required signed system libraries too. Review dependency identity, scripts, integrity/provenance and advisories before adding/updating packages (ADR 003); keep TLS, signatures and integrity checks enabled. `pnpm audit` reports known advisories, not a guarantee of uncompromised dependencies.

`pnpm build` writes the production extension to apps/extension/.output/chrome-mv3. `pnpm build:test` writes a separate localhost-only automation build to .output-test, with a worker-only activation hook. Never distribute .output-test. Production action testing uses Chrome's native browser-level Extensions.triggerAction capability, on an isolated test browser with its explicit debugging flag; the shipped artifact has no such flag or test hook.

`pnpm package` checks the production manifest's three permissions (activeTab, scripting, storage), rejects broad permissions/static scripts/external connections, checks for test activation and dynamic/remote executable code, and creates dist/accesslab-0.1.0-chrome.zip plus .zip.sha256. It includes installation instructions, local docs, actual bundled-package inventories and full licenses, project MIT notice and axe-core source form. Extract, enable Chrome Developer mode and Load unpacked from the extracted directory. This creates no store publication or public release.

Archives use sorted files, fixed timestamps/permissions and stored ZIP entries, so the archiver does not depend on compression-library variations. Locked build output must also be identical: compare hashes across repeated builds and clean source checkouts. The checksum file uses standard SHA-256 format (`sha256sum -c accesslab-0.1.0-chrome.zip.sha256` from dist/). Output is ignored in Git.

The GitHub workflow uses official actions pinned by commit, Node/pnpm pins, frozen install, official Playwright browser installation, all gates and packaging. Token permission is contents:read, checkout credentials are not retained, runs cancel superseded revisions, synthetic failure artifacts expire after three days and production artifacts after seven. No secrets, deployment, release tag or upload to a store is required. T15 evidence records actual local/remote outcomes; a configured workflow alone is not proof of a successful remote run.
